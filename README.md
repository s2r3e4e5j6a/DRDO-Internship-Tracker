# 🚀 DRDO Internship Tracker

A Python + Streamlit application for tracking DRDO internship opportunities.

## Features

- Add Internship Records
- Delete Internship Records
- Search by Lab Name
- Filter by Status
- Days Left Calculation
- Dashboard Analytics
- Download CSV Data
- Internship Deadline Alerts

## Technologies Used

- Python
- Streamlit
- Pandas
- BeautifulSoup
- Requests

## Project Structure

DRDO-Internship-Tracker
│
├── app.py
├── scraper.py
├── requirements.txt
├── README.md
│
└── data
    └── internships.csv

## Run the Project

```bash
streamlit run app.py
```
